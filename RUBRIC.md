# Rubric

**Terse is durable.** Every sentence in a durable document is charged to every reader it will ever have, so each earns its place under the rules below or goes.

**Bindings.** Each knowledge base names the four things this rubric leaves open, in the file every session reads. Its source of truth is the artifact that is the specification. Its homes are the documents that hold substance. Its lifecycles say where settled truth, work in flight and conversation each live. Its slots are its top-level directories beyond those `core/README.md` §Slots fixes, each with what it admits and whether git tracks it. Each binding names a thing, never a step or a rule.

## 1. What earns a place

**Source Test.** Never restate what the source of truth says. Say where it lives, because finding it is the work a document saves. Derivability decides, whatever the form.

**One Home.** Every fact lives in exactly one home, and everything else points to it. Name where a sentence's content already lives. If it has a home, cut the sentence. If it deserves one and has none, give it one.

**Ghost Correction.** Write what is true, never what changed. Point to the sentence in the current document that creates the false belief. If there is none, delete the correction. If there is one, fix that sentence instead. Overwrite text rather than marking it superseded or tagging its status. A rejected option survives as one sentence inside the rule it shaped.

**Cold Reader.** A writer applies these tests as it writes, but the verdict on the finished document is never its own. A writer cannot un-know its session, so every sentence it wrote reads as necessary to it. The grader is a fresh agent that never had the session, and never a fork of the writer's conversation, which carries the session with it. It asks first which question from a reader of the finished document each sentence answers. No question, no sentence. A skill, or a document at the root of the knowledge base or of the core, is graded after every change, through `cold-read`; any other document may wait for a pass over many.

**No Examples.** A statement never carries the instances it covers. A list survives only where every item in it is meant to be used or copied, because then it is the data itself. A specimen of voice never qualifies. A rule that needs an example to be applied has a test not yet written.

## 2. Where it goes

**Lifecycle Test.** Ask what would have to happen for the sentence to stop being true. If an event in the work would falsify it, it is work state and lives with the work. If only a change to the thing itself would, it is durable.

**Altitude.** A fact goes in the narrowest document whose scope contains it. A misfiled fact is moved, never dropped.

**One Way.** Knowledge moves from conversation to work in flight to settled truth, and never back.

**Declared Slots.** A writer creates no top-level directory: each is a slot the knowledge base declares or the core fixes. Where none admits its file, the writer raises the gap with the user.

**No Memories.** Agent memory stays off. A lesson goes into the document it corrects.

## 3. How the rubric is kept

**Fix by Subtraction.** Find what caused a failure and remove it before adding anything. A rubric clause added after a failure stays only if a fresh model would make that failure unprompted.

**Named Rules.** Every rule carries a short name, so a correction costs one word.

**Just in Time.** A rule loads where the writing happens, not in a file every session reads.
